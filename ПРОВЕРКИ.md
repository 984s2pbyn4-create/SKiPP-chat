# СКиПП v4.3 — отчёт о проверках

## Автоматические проверки

- OK: PIN-обработчики сохранены
- OK: Шифрование резервных копий сохранено
- OK: Восстановление подтверждается пользователем
- OK: Проверка размера импортируемого файла
- OK: Запрет экспорта при незавершённом сохранении
- OK: Режим только чтения при сбое localStorage
- OK: Диагностика доступна в настройках
- OK: Версия офлайн-кэша
- OK: Исходный формат данных не изменён

- OK: синтаксис app.js и sw.js (Node.js --check).
- OK: целостность ZIP всех трёх выпусков.

## Ограничения

Это статические проверки, а не интеграционные испытания. Не проводились тесты в браузерах iOS/Android, реальная проверка PIN, миграций IndexedDB, автономной установки, восстановления резервных копий и нагрузочные замеры. Поэтому v4.3 — кандидат в стабильный релиз, а не подтверждённая безошибочная версия.

## Перед установкой

Сохранить JSON-копию данных в текущей версии. Установить содержимое ZIP v4.3 в корень GitHub Pages. Проверить загрузку данных, PIN, редактирование задач, экспорт и импорт на резервном устройстве или тестовой копии.
