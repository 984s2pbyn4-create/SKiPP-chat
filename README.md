# СКиПП v4.4 — Security & Reliability Fix

Сборка для GitHub Pages. Содержит исправления по аудиту v4.3: согласованный сброс PIN и данных в IndexedDB/localStorage, ограничение сложности импортируемых JSON, разделение основной записи IndexedDB и зеркала localStorage, усиленное предупреждение об открытых резервных копиях, минимальная длина нового пароля резервной копии 12 символов, предупреждение об офлайн-переборе PIN.

**Важное ограничение:** короткий цифровой PIN по-прежнему не является стойким секретом для шифрования при офлайн-доступе к базе. Полное устранение этого риска требует отдельной миграции к длинному паролю для локальной базы.

Перед обновлением создайте резервную копию. Проверены синтаксис и структура архива, но не проведены браузерные интеграционные испытания.
