# СКиПП v4.3 Stable

Итоговая стабильная кандидат-сборка на основе v4.2. Формат данных и внешний вид не менялись. Статус Stable обозначает завершение запланированного цикла изменений, но не подтверждает отсутствие ошибок на реальных устройствах.

Включены все предыдущие изменения. Перед обновлением сохраните резервную JSON-копию базы. Распакуйте файлы в корень GitHub Pages.

Проверки: node --check для app.js и sw.js, проверка архива, статические инварианты; полноценное браузерное тестирование не проводилось.
